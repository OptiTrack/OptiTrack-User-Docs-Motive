# Wired AnchorPuck

## Overview

The Wired AnchorPuck is OptiTrack’s purpose-built ActiveIO tracking tool for virtual production, studios, and stages.&#x20;

<figure><img src="../../.gitbook/assets/Wired AnchorPuck Dual View.jpg" alt="Closeup and longer-range views of the Wired AnchorPuck with marker cables extended. "><figcaption></figcaption></figure>

#### Power

Powered and connected to the camera system through a PoE/PoE+ switch, the Wired AnchorPuck is able to use higher-powered LEDs than a battery-operated Puck. Without a battery to charge, the Wired AnchorPuck is a set-it-and-forget-it device.

#### Origin

With a maximum of 12 extended markers that can be attached and placed at specific, non-changing points of reference in the volume, the Wired AnchorPuck is good for [setting origin](../../motive-ui-panes/builder-pane.md#align-to-origin) in your capture volume. It can also be used to make a large rigid body that does not move such as a screen or large display.

#### Ease of Use

The Wired AnchorPuck’s settings can be changed directly within Motive software. This lets you quickly reconfigure the Wired AnchorPuck in place whenever needed.&#x20;

## Quick Start Guide

### Requirements

Motive 3.5 or later.

Ethernet/PoE+ port or switch.

Cat 6a Ethernet cable.

### Setup

The Wired AnchorPuck needs no assembly before use.

### Mount the Wired AnchorPuck

The Wired AnchorPuck has five mounting options, to accommodate different environments and mounting surfaces.&#x20;

{% tabs %}
{% tab title="Flat Strap  Mount" %}
The Flat Strap mount has 2 hook-and-loop straps that wrap around a flat surface to which the Wired AnchorPuck is mounted.&#x20;

* Insert the Wired AnchorPuck into the mounting panel and secure it using the 4 locking knobs. &#x20;
* Wrap the straps around the surface, pulling each strap through its loop until secured.

<figure><img src="../../.gitbook/assets/Flat Strap Mount CROPPED.png" alt="OptiTrack Wired AnchorPuck Flat Strap Mounting Hardware"><figcaption></figcaption></figure>
{% endtab %}

{% tab title="Pipe Strap Mount" %}
The Pipe Strap mount has 2 hook-and-loop straps that wrap around a cylindrical surface as wide as 3 feet in diameter, such as a pipe or speed rail.&#x20;

* Insert the Wired AnchorPuck into the mounting panel and secure it using the 4 locking knobs. &#x20;
* Position the mount with the pipe grip against the pipe.&#x20;
* Wrap the straps around the pipe, pulling each strap through its loop until secured.

<figure><img src="../../.gitbook/assets/Pipe Strap Mount.png" alt="OptiTrack Wired AnchorPuck Pipe Strap Mounting Hardware"><figcaption></figcaption></figure>
{% endtab %}

{% tab title="¼-20 Mount" %}
The 1/4-20 mount attaches the Wired AnchorPuck to a 1/4-20 standard tripod mount.

* Insert the Wired AnchorPuck into the mounting panel and secure it using the 4 locking knobs. &#x20;
* Attach the mount to the tripod.

<figure><img src="../../.gitbook/assets/1 quarter 20 Mount.png" alt="OptiTrack Wired AnchorPuck 1/4-20 Mounting Hardware"><figcaption></figcaption></figure>
{% endtab %}

{% tab title="Bolt Mount" %}
The Bolt mount attaches the Wired AnchorPuck to a surface using as many as 5 M5 bolts.

* Insert the Wired AnchorPuck into the mounting panel and secure it using the 4 locking knobs. &#x20;
* Attach the mount to the surface using M5 bolts.

<figure><img src="../../.gitbook/assets/Bolt Mount.png" alt="OptiTrack Wired AnchorPuck Bolt Mounting Hardware"><figcaption></figcaption></figure>
{% endtab %}

{% tab title="ARRI Mount" %}
The ARRI mount attaches the Wired AnchorPuck to a surfacing using an anodized aluminum ARRI interface.

* Insert the Wired AnchorPuck into the mounting panel and secure it using the 4 locking knobs. &#x20;
* Attach the mount to the tripod using a single ARRI connector.

### Attach the LED Cables

Attach the LED cables (which are sold as optional accessories with the AnchorPuck) to the ports on either side of the Wired AnchorPuck. At least 1 LED cable is required, up to 12 can be attached.&#x20;

LED cables come in various lengths that can be extended with the optional Extension Cables as needed.&#x20;

{% hint style="info" %}
In some instances, you might find it more efficient to attach the LEDs prior to mounting the puck, to ensure that all LED cables can reach the location you mount the Wired AnchorPuck.  &#x20;
{% endhint %}

### Connect to the Camera Network

Connect the Wired AnchorPuck to a PoE/PoE+ switch on the camera system network using a shielded Cat 6 or Cat 6a Ethernet cable. The latter is highly recommended.

### Status LEDs

* **Solid Green:** Initialization phase 1 (device has power).
* **Solid Yellow:** Initialization phase 2 (firmware is running).
* **Slow-Blink Green:** Initialization phase 3 (switch communication established, awaiting IP address).
* **One-Second Blink Yellow:** Initialization phase 4 (in the process of synchronizing).
* **One-Second Blink Green:** The device is synchronized with the camera group.&#x20;
* **Alternating Yellow:** Firmware is updating.
* **Solid Blue:** The device is hibernating.
* **One-Second Blink Red:** Error.

### Active Marker LED Specifications

The following specifications apply for active IR LEDs on the Wired AnchorPuck:

* 850 nm IR spectrum
* 12 LEDs
* LED Output High
* Illuminations synchronized with camera exposures
* Optical Detection Distance: 60m as tested with a PrimeX 41 camera. Note that this can vary based on application.&#x20;

## Command Bar

The Command bar contains menus of related commands. This section covers the items available on each menu.

<figure><img src="../.gitbook/assets/image (90).png" alt="A screenshot of the Command Bar in Motive."><figcaption><p>The Command Bar in Motive.</p></figcaption></figure>

### File

The File tab contains commands related to opening, importing, exporting, and saving Motive files.&#x20;

<figure><img src="../.gitbook/assets/File Menu 3.3.png" alt="A screenshot of the File tab menu in Motive. "><figcaption><p>The File tab in Motive.</p></figcaption></figure>

<details>

<summary>Open File...</summary>

Prompts the user to select a file to open. Applicable files include Take files (.tak), Camera Calibration files (.mcal or .cal), Motive user profile (.motive), <mark style="background-color:blue;">and XML files.</mark>&#x20;

</details>

<details>

<summary>Open Folder...</summary>

Imports a session folder into Motive. All of the TAK files within the session folder will be loaded in the [Data pane](data-pane.md).

</details>

<details>

<summary>Import Shot List...</summary>

Import a list of _Take_ names to record from a CSV or XML file that contains _Take_ names on each row. This allows users to plan which motions to capture ahead of the time (Please see the  [Data Recording](../motive/data-recording/) page for more detail).&#x20;

</details>

<details>

<summary>Open Recent</summary>

Shows a list of Motive-compatible files that were recently loaded into Motive.

</details>

<details>

<summary>Save Take</summary>

Saves currently opened _Take_.

</details>

<details>

<summary>Save Take As...</summary>

Prompts the user to select a filename and a directory to save the current _Take_.

</details>

<details>

<summary>Save All Takes</summary>

Save all _Takes_ from all of the sessions loaded in the [Data pane](data-pane.md).

</details>

<details>

<summary>Export Tracking Data...</summary>

Exports tracking data from a selected Take into the desired output format. See: [Data Export](../motive/data-export/).

</details>

<details>

<summary>Export Video...</summary>

Exports reference video to an AVI file. To play this file in Windows Media Player, a codec needs to be installed.

</details>

<details>

<summary>Export Audio...</summary>

**E**xports audio to into a WAV file. See: [Audio Recording in Motive](../motive/audio-recording.md).

</details>

<details>

<summary>Export Calibration...</summary>

Exports the current system calibration file (.mcal) to a desired location.

</details>

<details>

<summary>Export Profile As...</summary>

Exports the current software configurations into an application profile (MOTIVE).

{% hint style="info" %}
**Profile (MOTIVE) files:** the MOTIVE profile stores software configurations. Software setting such as applications settings, streaming settings, trackable assets, synchronization configurations, and/or device configurations are saved into this file. The profile file can be exported and imported into Motive.
{% endhint %}

</details>

<details>

<summary>Export Assets...</summary>

Export just the [assets](../motive/assets/) (Rigid Bodies, Skeletons, Trained Markersets) to a MOTIVE file.

</details>

<details>

<summary>Export Device Info...</summary>

Exports the devices currently connected to Motive into a CSV file (i.e., Cameras and their serial numbers).

</details>

<details>

<summary>Update Default Profile</summary>

Manually update the current software configurations onto the [default system profile](../motive/motive-basics.md). The default profile loads when launching Motive and is located at: `C:\ProgramData\OptiTrack\MotiveProfile.motive`.

</details>

<details>

<summary>Exit</summary>

Closes the Motive application.

</details>

### Edit

The Edit tab contains commands related to editing tasks and changing application settings.&#x20;

<figure><img src="../.gitbook/assets/Edit menu (1).png" alt="A screenshot of the Edit tab menu in Motive. "><figcaption><p>Options under the Edit tab.</p></figcaption></figure>

<details>

<summary>Undo</summary>

Reverts the last data processing action (i.e. deleting data, merging markers, filling gaps).

</details>

<details>

<summary>Redo</summary>

Reverts an Undo.

</details>

<details>

<summary>Trim Current Take</summary>

Archives the original take file and crops to the working range selected in the [Graph View pane](graph-view-pane.md). For more information, read the [Trimming Captured Takes](../motive/data-editing.md#trimming-captured-takes) page.

</details>

<details>

<summary>Settings...</summary>

Opens the Application Settings pane.

</details>

<details>

<summary>Reset Settings</summary>

Sets all application settings to the default setting.

</details>

### Layout

The layout tab allows you to select preset layouts that contain panes applicable to a specific task. This tab also contains commands that allow you to create and manage your own custom layouts.&#x20;

<figure><img src="../.gitbook/assets/Layout menu (1).png" alt="A screenshot of the Layout tab menu in Motive. "><figcaption><p>Options under the Layout tab.</p></figcaption></figure>

<details>

<summary>Calibrate</summary>

Displays panes applicable to system calibration. (Cameras, Perspective View, Camera Preview, Camera Calibration, Reconstruction)

</details>

<details>

<summary>Create</summary>

Displays panes applicable to asset creation and modification. (Project, Perspective View, Timeline, Skeleton, Rigid Bodies)

</details>

<details>

<summary>Capture</summary>

Displays panes applicable to capturing a take. (Project, Perspective View, Timeline)

</details>

<details>

<summary>Edit</summary>

Displays panes applicable to editing a take. (Project, Perspective View, Timeline, Edit Tools).

</details>

<details>

<summary>Create Layout</summary>

Saves the current layout. Saved custom layouts can be accessed from the drop-down menu located at the top-right corner of Motive or from the Layout menu.

</details>

<details>

<summary>Delete Layout</summary>

Deletes the saved custom layout.

</details>

<details>

<summary>Update Current</summary>

Updates the selected custom layout from the drop-down menu located at the top-right corner of Motive.

</details>

<details>

<summary>Set as Default</summary>

Sets the current layout as a default layout setup for starting Motive.

</details>

<details>

<summary>Custom Layouts</summary>

List of custom layouts that are created by the user. In the screenshot above, "My Layout," "Sample Layout," and "User Created "Layout" are examples of user-defined layouts.

</details>

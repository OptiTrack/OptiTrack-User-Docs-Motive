# USB Cameras

{% hint style="danger" %}
USB camera models, including Flex series cameras and V120:Duo/Trio tracking bars, are currently not supported in Motive 3.0.x versions. Those systems are supported in Motive 3.1 and later. USB cameras are also supported in [Motive 2.x](https://app.gitbook.com/o/6K2GcxpSS9y4e9SRLTrx/s/TSFWA3dBvgCMGQlNWsHE/).
{% endhint %}
